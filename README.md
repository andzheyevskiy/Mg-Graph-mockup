# Mg-Graph-mockup

## Rutas:
`/users`

Manda información de todos los usuarios(no externos).

**`/users?user=<userId>`**

Manda información del usuario(no externos) con el id indicado.

`/externalusers`

Manda información de todos los usuarios externos.

`/externalusers?user=<userId>`

Manda información del usuario(solo externos) con el id indicado.

`/mfa`

Manda el estado del registro de MFA.

`/groups`

Manda informacion de todos los grupos.

`/groups?group=<GroupId>`

Manda informacion del grupo con el id indicado.

`/devices`

Manda informacion simple de todos los dispositivos.

`/devices?device=<DeviceId>` 

Manda informacion simple del dispositivo con el id indicado.

`/devicesFull`

Manda informacion extendida de todos los dispositivos.

`/DAC`

Manda informacion de todas las directivas de Acceso condicional.

`/Bitlocker`

Manda información de BitLocker de todos los dispositivos.

`/BitLocker?deviceId=<DeviceId>`

Manda informacion de BitLocker del dispositivo con el id indicado.
